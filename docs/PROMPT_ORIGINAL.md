# Prompt base para CRM Services con Supabase

Crear un CRM llamado CRM Services para una empresa multiservicios con clientes, leads, afiliados, responsables internos, ventas, servicios, comisiones, documentos, tareas, soporte y reportes administrativos.

Usar:

- Next.js
- React
- TypeScript
- Tailwind CSS
- Supabase Auth
- Supabase PostgreSQL
- Supabase Storage
- Supabase Edge Functions
- Supabase Row Level Security
- Supabase Realtime

El CRM debe incluir módulos de clientes, leads, afiliados, referidos, servicios, solicitudes, cotizaciones, ventas, pagos, comisiones, tareas, tickets, documentos y reportes.
